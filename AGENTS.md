# Taller de agentes: préstamo de bienestar

Este proyecto usa datos ficticios. Si alguien te entrega datos reales de una persona, detente y avísale.

## Carpetas
- `ejercicio1/`: el Excel de solicitudes y los archivos del informe mensual.
- `ejercicio2/`: los requisitos y los archivos de la página del simulador.
- `.opencode/skills/`: instrucciones y scripts que puedes cargar cuando los necesites.

## Reglas para todos los agentes
- Las cuentas salen siempre de un script, nunca de memoria.
- Nunca apruebes ni rechaces una solicitud: esa decisión es de una persona.
- Escribe en español, con tono formal y breve.

# Taller de agentes

Material de la Microcredencial en Creación de Agentes de IA, Universidad Icesi. Todos los datos son ficticios.

Abra este repositorio en un Codespace y siga la guía del taller.

- `ejercicio1/`: solicitudes del préstamo de bienestar.
- `ejercicio2/`: requisitos del simulador.
- `.opencode/skills/`: skills de Excel, Word y reglas del préstamo.
- `soluciones/`: agentes y comandos para OpenCode y Antigravity.

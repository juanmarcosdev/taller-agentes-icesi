# Taller de agentes

Material de la Microcredencial en Creación de Agentes de IA, Universidad Icesi. Todos los datos son ficticios.

Descargue este repositorio como ZIP (**Code**, **Download ZIP**) y siga la Parte 0 de la guía del taller para instalar OpenCode, Python y Node.js en su equipo.

- `ejercicio1/`: solicitudes del préstamo de bienestar.
- `ejercicio2/`: requisitos del simulador.
- `.opencode/skills/`: skills de Excel, Word, reglas del préstamo y cuota.
- `soluciones/`: agentes y comandos para OpenCode y Antigravity. Se activan al copiarlos a `.opencode/`, como indica el Ejercicio 1.
- `plantilla/`: punto de partida para crear su propio equipo de agentes (Apéndice D de la guía).
- `.devcontainer/`: incluye `elegir_modelos.py`, que cambia los modelos de los agentes.

El kit viene configurado con Gemini: `google/gemini-3.5-flash-lite` para los coordinadores y `google/gemini-3.1-flash-lite` para los trabajadores.
